# Khushi's CAT Diary 💗

A small revision site for CAT 2026, made by Vikas for Khushi.

- **Quick quizzes** for Math, VARC and LRDI (10 random questions a round)
- **Math topics**: a quick revision with examples for every topic, plus timed tests for the topics already covered
- **VARC and LRDI** revision notes for free time
- **Tracker**: topic status, weakness board, error log and calendar
- **Love notes and a kiss jar** 💋

Plain HTML, CSS and JavaScript; no build step. Progress (kisses, streak, quiz scores, test answers) is saved in the browser.
