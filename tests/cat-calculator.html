Practise on the CAT calculator

The real CAT gives you a basic on-screen calculator (TCS calls it the Normal Calculator), not a scientific one. The one on this page copies its keys and its rules, so nothing surprises you on 29 Nov. Click the orange calculator icon at the top right to open it, the same place it sits in the exam (just above the timer). It is in every test page too.

What is on it

  • Numbers and + - * / = .
  • sqrt square root, 1/x reciprocal, +/- change sign, % percent
  • ← deletes the last digit, C clears everything
  • Memory: MS save, M+ add to memory, M- subtract from memory, MR bring it back, MC wipe it. A small M shows when memory holds something.

What is NOT on it

  • No brackets, no x², no powers, no cube root, no log. For 1.08³ press 1.08 * 1.08 * 1.08 =.
  • No keyboard. You click every key with the mouse. Typing digits on the keyboard does nothing.
  • A number can be at most 9 characters long (the dot counts).
  • For TITA answers you type the number into the answer box yourself, using the exam's on-screen number pad.

3 rules to know before the exam

1. It does × and ÷ before + and − (BODMAS). 2 + 3 * 4 = gives 14, not 20. So for (5230 − 4610) ÷ 4610 press = after the subtraction first, then divide.

2. % means "percent of". 6480 % 15 = gives 972 (15% of 6480). It is not the Windows-calculator %, so don't try 6480 + 15%.

3. Use it only when the arithmetic is truly ugly. Clicking 4–5 digit numbers with a mouse takes 15–30 seconds. In Quant, most answers come faster from options, units digits and rough values. In DILR it saves real time.

Try first: open the calculator and press 2 + 3 * 4 =. You should see 14. Do the same once in the official CAT mock to confirm.
